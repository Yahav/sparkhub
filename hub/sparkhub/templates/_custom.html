The third mode, next to Fast and Quality. Import a sparkrun recipe, review it, approve it with a fresh 2FA code, then download and verify it. After that you can assign it to Custom and load it above. Nothing runs before that. When it does run, it is isolated: an internal Docker network with no route out, Hugging Face in offline mode, and the model files mounted read-only.

Import a recipe

Import only reads metadata from GitHub, Hugging Face and the image registry. It downloads no image or weights and runs nothing. The recipe then waits for your review. Only vLLM recipes that run on one Spark are accepted.

A pasted or uploaded recipe has no source, so it gets no update notices.

Browse registries

Lists recipe files from GitHub repositories in sparkrun's registry layout. Browsing reads only text: the recipe files, and the files of any mods they name (to check that the mods don't need the network). Recipes marked needs a mod run sparkrun patch scripts before the server starts; the review page shows them in full. Registries are off until you turn them on.
