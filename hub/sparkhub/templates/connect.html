Windows: double-click → Install → Current User → Trusted Root Certification Authorities. macOS: double-click → Keychain Access → open the certificate → Trust → Always Trust. iPhone/iPad: open the file → Settings → Profile Downloaded → Install, then General → About → Certificate Trust Settings → turn it on. Android: Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Linux: sudo cp ca.crt /usr/local/share/ca-certificates/sparkhub.crt && sudo update-ca-certificates (Firefox: Settings → Certificates → Import).     3. {% endif %}
  3. Get the CLI (Python 3, nothing to install): 
    mkdir -p ~/.config/sparkhub ~/.local/bin

For clients that search their own documents (RAG, code search, semantic search): the same base URL and API key as above, OpenAI-compatible. The hub only computes vectors; it stores nothing, so keep the vectors in your own database (pgvector, sqlite-vec, Qdrant, Chroma…).

  • Embed with model {{ es.embed.served_name }}: {{ embed.dimensions }} numbers per text, 100+ languages (Hebrew included). Up to {{ es.embed.max_input_tokens or 4096 }} tokens per text, so split long documents into chunks (a few hundred tokens each works well). Send many texts in one request as a list.
  • Queries get an instruction, documents don't: embed documents as they are, and prefix each search query with Instruct: Given a web search query, retrieve relevant passages that answer the query\nQuery: (a newline before Query:). Use the same model and size for both.
  • Smaller vectors: "dimensions": 256 (32–{{ embed.dimensions }}); "encoding_format": "base64" for compact responses.
    • {% if embed.rerank_enabled %}
  • Rerank with model {{ es.rerank.served_name }}: sends a query and up to 1000 candidate texts, returns them scored by relevance. Use it on the top 20–50 results of a vector search for better ordering.
    • {% endif %}
  • {% if embed.run_mode == "on-demand" %}It runs on demand: the first request after an idle period takes ~2 s longer. {% endif %}Large embedding requests wait while chat requests are running (at most {{ embed.hold_s }} s).
