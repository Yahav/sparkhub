Chat chat-ui at /chat/

A ChatGPT-style web chat for the hub's users, signed in with the hub login. Each user has their own history. It uses the loaded model (auto); turning it off stops its container and closes /chat/, and keeps the history.

Notifications ntfy

Push notifications from the hub (model crashed or restarted, switch or backup failed, a stack container such as Grafana down for a minute, started/ready) and from Grafana's alert rules. Subscribe to the topic in the ntfy app. Anyone who knows the topic can read the notifications, so use a long random one.

Updates this install runs {{ cfg.version }}

Once a day the hub asks GitHub for the newest SparkHub release ({{ cfg.update_repo }}). Nothing about this install is sent. A newer release shows a notice to admins and sends one notification. Upgrading runs on the Spark, over SSH: ./install.sh upgrade shows the release notes, backs up the database, downloads what the release needs and restarts what changed. A model whose pinned version changed reloads during the upgrade (~4–5 min).
